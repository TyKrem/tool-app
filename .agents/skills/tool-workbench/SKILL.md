# 工具交互约束

- `common.js` 的 `makeEditor` 返回 `ta` / `root` / `scroll` 等引用。直接赋值 `ta.value`
  不会更新行号、结果有效性或页面提示；需要触发 `input`，或同时调用
  `refreshEditor` 与对应页面的输入处理函数。文件导入走前者。
- 只读编辑器仍允许键盘聚焦和选择。不要用 `tabIndex=-1` 排除它。
- `addDownload` 跟随复制按钮的 `disabled`，所以结果是否有效由页面负责。
  输入、模式、选项改变后先使结果失效；折叠与展开不能重新启用已过期的结果。
  JSON 的延迟解析期间也不能导出上次结果。
- JSON 的 `valid` 与 `data` 分开判断；`null`、`false`、`0`、空字符串都是合法结果。
  折叠只改变展示，复制与下载序列化完整 `data`。
- 正则只在 `regex-worker.js` 执行。页面的 `stopWorker` 同时终止线程、清除超时、
  恢复按钮；输入改变和清空都走失效入口，防止迟到结果覆盖新输入。
  Unicode 零宽匹配按码点推进，不能只给 `lastIndex` 加 1；保留未命中捕获组的槽位。
- 时间戳实时时钟复制 `state.liveMillis`，保持暂停状态与显示值一致。
  快捷日期按本地自然日生成，不用固定 86400000 毫秒加减。

核心集合和编码逻辑的测试在 `test/*-core.test.js`。真实浏览器检查同时覆盖
原有桌面一屏布局与新工具交互；后者需要实际文件选择、剪贴板和下载行为，
不能只检查按钮文字。静态部署要包含 Worker，不能只同步 HTML。
